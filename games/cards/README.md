# アニマルカードバトル 0.4.0

操作演出: ボタン・カードの押下反応、選択カードの浮き上がり、詳細画面の表示、召喚・攻撃・被弾のアニメーションを強化。カードへのダメージと本体へのダメージを大きな数字で表示します。2端末対戦にも召喚・被弾・体力減少の表示を追加。端末の「動きを減らす」設定では移動演出を抑え、数値は表示します。

チームバトルと同じ「PCでLANサーバーを起動し、同じWi-Fiの2端末が部屋番号で参加する」構成です。CPU戦、1端末を交代で使う対戦、チュートリアルも残しています。カード24種類・イラスト・ゲームのルールは変更していません。

## 2端末で遊ぶ

1. Node.js が入ったPCで `LAN対戦を起動.cmd` を開きます。このウィンドウは対戦中開いたままにします。
2. 表示される `Same Wi-Fi: http://…:8771/` のアドレスを、同じWi-Fiにつながった2端末で開きます。PC自身も参加できます。
3. 両方で「2だいで たたかう」を選び、片方は「へやを つくる」。もう片方は表示された6桁の番号で入ります。先攻・後攻はランダムです。

チームバトルの8770とは別の8771を使うので同時起動できます。Windowsがアクセス許可を求める場合は、家庭のプライベートネットワークで許可してください。端末がつながらない場合は同じWi-Fiか、PCのファイアウォール・ゲストWi-Fiの端末間通信制限を確認してください。

再読み込みするとURL内の復帰情報から戻ります。「へや」で自分専用の「ふっきの あいことば」をコピーしておけば、ページを閉じた後にも復帰できます。対戦相手には6桁の部屋番号だけを伝え、復帰情報を含むURL・あいことばは共有しないでください。ブラウザのlocalStorageは使いません。

通信が途切れても勝手にCPUへ交代しません。接続が戻るまで待ち、送信済み操作は重複させず再送します。PCのサーバーを終了・再起動すると部屋は消えます。2時間通信がない部屋も消えます。

## 公開版への統合

このフォルダを既存の `games/cards` に統合するための候補として用意しています。本家のファイルは変更していません。

公開用の完成品は `index.html` です。1端末の各モードは従来どおり単一HTMLで動きます。公開サイト上の「2だいで たたかう」からPCのアドレスを入力し、「おうちの たいせんへ →」でLAN対戦ページへ移動できます。IPアドレスだけなら8771番を補います。入力先はURLの `#home=` に残るので、戻った公開ページをブックマークすると再入力を省けます。家庭のIPアドレスはファイルに埋め込みません。

静的サイトへのHTML公開だけでは2端末通信は動きません。チームバトル同様、LAN対戦には同じWi-FiとPC上のサーバーが必要です。

## 編集・検証

依存パッケージのインストールは不要です。Node.js 18以降を使用します。

```
node build.js
node run_sim.js
node ui-tests.cjs
node lan-tests.js
node lan-server.js
```

- `source.html`: 統合前の本家HTMLを保持したビルド用ベース。
- `app.js` / `engine.js` / `ai.js`: 抽出した既存UIとルール。ビルド時に通信処理を接続します。
- `lan-client.js` / `lan.html` / `lan.css`: 通信画面と再接続・操作処理。
- `lan-server.js`: サーバーでルールと操作順を検証。本人の手札だけを送り、相手の手札・山札内容・伏せたカード名は送りません。

確認済み: 既存100項目とCPU1,000試合、UI・通信クライアント85項目、HTTP経由12試合完走、再送の重複防止・手札秘匿・再接続・手番検証。UIの検証はDOMを模した自動テストで、実機スマホ2台での表示・操作確認は未実施です。
