# ひがしやま チームバトル！ — 1.1 リリース候補

人間1人＋CPU7人の8人制オートバトル。家族5人のリーダー、60種類の仲間、13種類の能力。スマホ横持ち、PCのタッチ・マウス・キーボードに対応。

## 今回の変更

- 仲間を48種から60種へ拡張。各お店レベルに12種ずつ。
- シールド、回復、反撃を受けない攻撃、発明支援、毎ターン成長、退場時のバトンを追加。
- questのキャラクター画像を60枚、別々のカードに再利用。画像はHTML内に埋め込み、元のquestは変更しない。
- 準備画面はお店を上、控えを中央、自陣を下に固定。
- 所有・店頭・相手・戦闘・報酬・図鑑のカードをいつでも拡大。タップ・長押し・右クリック対応。
- 所有カードの詳細から配置変更と売却へ進む。売却確認と1操作分の取り消しを追加。
- 戦闘後は必ず8人の順位表を表示。前ラウンドからの上下・ハート減少・脱落が分かる。
- 60枚のカード図鑑、難易度2段階、設定画面、BGM・SE、全画面化を追加。
- チームが空のまま出撃すると確認。満員でも3枚目なら購入・合成できる。
- あいことばで試合の途中を別端末へ引き継げる。localStorage・アカウント・サーバー保存は使わない。

## 遊び方

1. リーダーと難易度を選び「あそぶ」。
2. 上のお店のカードをタップし、説明を読んで3コインで購入。
3. 下の自陣のカードをタップ。「ならべかえる」の後、移動先をタップ。
4. 「じゅんびOK」で戦闘。一時停止・コマ送り・倍速・スキップが使える。
5. 順位表で変動を確認し、次のお店へ。4位以内を目標にしよう。

攻撃値は与えるダメージ、体力は0になると退場。戦闘中のダメージは毎回リセット。購入効果と毎ターン成長だけは永続。詳しい条件とスター時の数値はカード詳細に表示。

## あいことば

お店の「あいことば」を押してコピーし、自分のメモ等に残す。タイトルの「つづきから」に貼り付けて再開する。

8人分の編成・お店・乱数状態を正確に復元するため、短い手入力用パスワードではなく圧縮されたコピー用コード。閉じる前に自分で保存する必要があり、自動保存はない。チェックサムで転記ミスを検出する。暗号化や改ざん防止認証を目的としたものではない。圧縮機能がないブラウザでは非圧縮形式を生成する。

## 開発と検証

```
node build.js
node run_sim.js
```

- `engine.js`: 市場・経済・能力・戦闘・順位・保存データの検証。
- `ui.js`: レイアウト・詳細・図鑑・入力・あいことば・BGM。
- `template.html`: ベース画面とアニメーション。
- `art.json`: quest由来の画像・切り出し情報と出典カードID。
- `build.js`: 上記を単一の `index.html` にまとめる。
- `run_sim.js` / `release_tests.js`: 自動検証。成果物のindex.htmlを直接編集しない。

300試合の自動対戦で完走・順位一意性・枠上限・経済を確認。40試合について各ラウンドの保存復元後も次の結果が一致することを検証。新能力、全カード詳細、売却取り消し、満員合成、画像の網羅性、保存入力の検証を追加。

## 現段階の境界

- 公開・pushは別工程。この変更はローカルのリリース候補。
- 実機iPhone/Androidでの最終操作確認と、子どものプレイテストによる数値調整は未実施。
- 最大20ラウンド。最終時の同点は内部ID順で順位確定。途中の順位表は同じハートを同順位と表示する。
- 戦闘は最大120手で引き分け。長い回復戦はスキップ可能。
- CPUの資金・価格は人間と同じ。やさしいは買い物判断を簡略化。ふつうも今後調整対象。
- 市場は独立在庫。通信対戦・協力・観戦専用モードは今回の対象外。


## 1.1.0-rc1: 星5と後半戦
カードは60種類（各星12種類）。星5はお店レベル5の各枠で1%。星4以上のお店でトリプルを作ると、星5を3種類から選べます。星5が生存して勝つと1体につき相手の体力に追加3ダメージ（スター合成でも同じ）。11戦目から追加ダメージが毎戦1増えます（11戦目+1、12戦目+2）。引き分けは両者にこの追加分だけを適用。星5追加分と決戦追加分は通常ダメージ上限の外です。
